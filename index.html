SHALL WE PLAY A GAME?

A terminal thriller inspired by WarGames (1983), with a modern AI-agent framing. The only winning move is to understand the machine.

Cloud models (e.g. openai/gpt-4o-mini) run on GitHub Models; the B3IQ options (e.g. gemma3:12b, qwen3:14b) run on the on-box GPU. The same proxy routes by the model id you pick.

If a request fails, the game falls back to scripted mode automatically.
