TYPOGRAPHY

Single family: . The UI relies on letter-spacing (1–4px) and case (UPPERCASE machine voice) rather than multiple fonts.

CRT LETTERING (THE DEFINING LOOK)

The signature 1983 low-fi look is not the font — it is a single .scanlines glass drawn over everything (top z-index, mix-blend-mode: multiply), so dark --scanline lines cut through every letter, plus a phosphor bleed (--glow-soft / --glow). This page carries the same overlay — the lines you see through this text are the effect. It must reach every surface (terminal, chess panel, NORAD, menus, console); any panel that renders above the glass and misses it looks "too clean / modern" and breaks immersion. That was the chess-panel bug: it sat above the scanline layer.

TEXT / VOICE CLASSES

bright — emphasis / titles (--fg-bright)
echo — quiet asides / links (--echo)
amber — section labels (--amber)
warn — cautions (--warn)
critical / alert — danger (--red)

SURFACES

PANEL
Standard panel: 1px solid --fg-dim, dark green fill, green glow box-shadow. Used by menu, Console, wiki, pair.

Panel fill alpha varies slightly across components (0.9 / 0.94 / 0.95 / 0.975). Candidate for a single --panel-bg token.

CAPTURED-PIECE TRAY (chess panel)

Pieces taken out of play, per side, under the move log (.cp-taken). Amber label (--amber), solid monochrome piece glyphs with the shared phosphor bleed — White uses --fg-bright, Black --fg-dim, exactly as on the board. The material edge badge (.cp-taken-edge) uses --fg-bright + --glow.

TIC-TAC-TOE BOARD

The tic-tac-toe panel is the same surface as the chess panel (.ttt-panel shares .chess-panel's rule) and its squares share .cp-sq; only the 3×3 grid and glyph size differ. X uses --fg-bright, O uses --fg-dim — the same bright/dim pairing the chess pieces use, so both games read as one machine.
